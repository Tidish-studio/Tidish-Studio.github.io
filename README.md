# DnD Spells 5e — Companion Site

Marketing and spell-download site for [DnD Spells 5e](https://play.google.com/store/apps/details?id=com.tidishstudio.spellbook),
a D&D 5e spell management app on Google Play.

Live site: https://tidish-studio.github.io/

## What it does

- Showcases the app and links out to the Google Play listing
- Lets visitors download spell-data JSON files to import into the app
- Hosts the app's privacy policy

Built with Vite + React + TypeScript, deployed to GitHub Pages.
